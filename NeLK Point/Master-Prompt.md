# 20. TASK VS SCHEDULE

Business rule:

Task ≠ Schedule.

Task:
Apa yang harus dilakukan?

Schedule:
Kapan dilakukan?

Contoh:

Database Assignment
→ duration 90 minutes
→ deadline Friday

Scheduler:
→ Tuesday 19:00–20:30

Task boleh belum mempunyai scheduled time.
